# audio/

Empty by design: Version 1 is a silent demonstration with burned-in captions. No professional voice-over, text-to-speech meeting the framework's quality bar, or licensed music is available (framework §14, §15, §17). When narration exists, re-render with `python project/render_pipeline.py --ffmpeg <path>` after adding an audio option; captions and timing in `project/content.py` are unchanged.

# 01 — Vision

should arbitrate design trade-offs everywhere else in this repository.

- Platform vision and mission statement
- Target market sequencing (SEBI-regulated Mutual Fund AMC first; Banking, Insurance,
  Healthcare, Government, Manufacturing, Technology, Critical Infrastructure as later
  regulatory profiles)
- Platform thesis: configuration-driven regulatory extensibility over forking
- Success criteria / what "done" looks like for each phase
- Non-goals — explicitly what ERM is not trying to be

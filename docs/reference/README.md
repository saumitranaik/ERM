# Reference

Primary source material — not authored in this repository, cited from it. These are the
regulatory inputs that ground the SEBI Mutual Fund AMC target market described in
[`../01-vision/`](../01-vision/) and [`../../CLAUDE.md`](../../CLAUDE.md).

## Contents

| File | Relevance |
|---|---|
| `Annexures to Master Circular for Mutual Funds as on March 31, 2023_p.pdf` | SEBI Master Circular annexures — primary source for [`../11-compliance/`](../11-compliance/) obligation register and [`../14-reporting/`](../14-reporting/) filing requirements |
| `Cyber Security and Cyber Resilience Framework for Mutual Funds AMCs (2019).pdf` | SEBI cyber resilience framework — primary source for the Cybersecurity Governance module ([`../05-modules/`](../05-modules/)) and [`../09-security/`](../09-security/) threat model requirements |
| `Risk Management System for Mutual Funds.pdf` | SEBI risk management circular — primary source for [`../10-risk/`](../10-risk/) taxonomy and methodology |

## Rules

- This folder holds source documents only — never edit or reformat the PDFs themselves.
- Every ERM spec that derives a requirement from a document here must cite it by filename
  (and section/page where practical) in its **Regulatory Requirement** traceability field
  (see [`../../CLAUDE.md`](../../CLAUDE.md#traceability-rules)).
- Additional regulatory source material (future regulatory profiles, updated circulars)
  should be added here with a corresponding entry in the table above — never left unindexed.

# 19 — Roadmap

## Purpose

Phasing and release planning for turning this specification into a delivered platform —
sequencing, not vision (see [`../01-vision/`](../01-vision/) for the "why" and "what
eventually").

## What belongs here

- Phase/release plan (e.g., Phase 1: Risk Register + Controls for SEBI AMC MVP; Phase 2:
  Audit + Compliance; Phase 3: additional regulatory profiles)
- Dependency ordering between modules (which specs/capabilities must exist before another
  can be built)
- Milestone definitions and what "shippable" means per milestone

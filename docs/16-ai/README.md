# 16 — AI

## Purpose

AI-assisted risk analytics capability specifications — where and how AI augments (never
silently replaces) governed risk/compliance decisions.

## What belongs here

- Candidate AI use cases (risk narrative summarization, anomaly detection on KRIs, control
  testing sample selection, regulatory change impact triage) each with explicit
  human-in-the-loop governance via PRSMTD's maker-checker pattern
- Model risk management: explainability, bias, and audit requirements for any AI-derived
  output used in a regulatory or executive decision
- Data governance boundaries for what data may be used for AI processing (privacy/compliance
  constraints from [`../09-security/`](../09-security/), [`../11-compliance/`](../11-compliance/))

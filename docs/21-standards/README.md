# 21 — Standards

## Purpose

Single source of truth for naming, documentation, and modeling conventions used across the
repository — referenced from [`../../CLAUDE.md`](../../CLAUDE.md#naming-standards) and
expanded here as it grows.

## What belongs here

- Detailed naming standards beyond the CLAUDE.md summary (document, ADR, diagram, API,
  workflow, entity, module, event naming)
- Modeling conventions (how to draw a state machine, what a "complete" data model spec
  looks like)
- Documentation style guide (tone, terminology consistency, traceability block usage)
- Glossary of repository-wide terms (distinct from per-bounded-context ubiquitous language
  in [`../04-domain-model/`](../04-domain-model/), which is domain vocabulary, not
  repo-process vocabulary)
